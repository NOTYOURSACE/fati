# Fatima Zain Birthday Surprise - React App

A fully responsive, interactive React birthday surprise website crafted with love for Fatima Zain by Zain.

## Features Included:
- 💖 Floating Heart & Star Canvas Particle Background
- 🔓 Unlockable Surprise Gate with Confetti Fireworks
- 🎂 Interactive Candle Blowing & Wish Generator
- ✉️ Interactive Sealed Digital Love Letter
- 🃏 Tap-to-Reveal 3D Reason Cards
- 📸 Photo Memories Lightbox Gallery
- 🎁 Birthday Surprise Gift Modal

## Setup & Running Locally:

1. Extract this zip folder.
2. Open terminal inside the project directory.
3. Install dependencies:
   ```bash
   npm install
   ```
4. Run the local development server:
   ```bash
   npm run dev
   ```
5. Open the local link (e.g. `http://localhost:5173`) in your web browser!
